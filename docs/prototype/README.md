# up-journey 高保真原型

4 个静态页面，用于在开工前确认「杂志编辑风」的审美方向。数据全部为假数据，地图为真实 ECharts 渲染。

## 查看

```bash
cd docs/prototype
python3 -m http.server 8613
# 打开 http://localhost:8613
```

> 需要通过 HTTP 服务访问（地图要 fetch 本地 GeoJSON，直接双击 file:// 会跨域）。

## 页面

| 文件 | 内容 | 看点 |
|---|---|---|
| `index.html` | 首页 | Hero 大标题、7 项数字统计、特写大卡、精选游记 |
| `footprints.html` | 足迹总览 | 中国地图（省份着色/城市标记/路线，可拖拽缩放）、游记卡片、时间轴（含天级子节点） |
| `trip.html` | 旅行详情 | 首字下沉的杂志式正文、行程小地图（景点级）、按天行程、景点分组图库 |
| `admin.html` | 管理端 | 完整录入表单：封面选图器、城市路线、景点+相册目录、坐标精调入口、天程、富文本 |

## 设计 Token

- 纸白 `#FAF9F6` / 墨色 `#1A1A1A` / **黛青（强调）`#2F4A5C`** / 辅助朱砂 `#B0532F`（仅地图城市标记）
- 标题与数字：宋体（Mac 上为 Songti SC；生产环境 self-host 思源宋体 Noto Serif SC 子集化 woff2）
- 正文：系统无衬线；间距 4px 基数；断点 1024 / 640
- 占位"照片"为 CSS 渐变色块（`ph-a` ~ `ph-f`），上线后即真实相册图

## 原型中已假装成立的约定

- 图片懒加载、缩略图/大图两档（真实后端 Pillow 管线）
- 地图数据 = 城市字典 + 景点坐标自动聚合
- 管理端"地图选点/相册插图"为静态占位交互
