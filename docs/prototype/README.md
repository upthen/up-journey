# up-journey 高保真原型

三套风格 × 独立版式，用于在开工前确认审美方向。数据全部为假数据，地图为真实 ECharts 渲染。

## 查看

```bash
cd docs/prototype
python3 -m http.server 8613
# 打开 http://localhost:8613/compare.html（风格对比导航）
```

> 需要通过 HTTP 服务访问（地图要 fetch 本地 GeoJSON，直接双击 file:// 会跨域）。

## 三套风格（版式各不相同，非换肤）

| 风格 | 位置 | 版式特征 | 页面 |
|---|---|---|---|
| 杂志编辑风 | 根目录 | 纵向阅读的编辑部版面：细线分栏、首字下沉、左对齐时间轴 | 首页 / 足迹 / 旅行详情 / 管理端 |
| 温暖手账风 | `warm/` | 拼贴桌面：拍立得照片墙、和纸胶带、登机牌特写卡、楷体注脚、锯齿交替时间轴 | 首页 / 足迹 |
| 深色画廊风 | `gallery/` | 沉浸展馆：统计压全幅大图、左出血展墙、横向拖动画廊走廊、编号展签目录、横向时间走廊 | 首页 / 足迹 |

- 地图配色随风格切换（`UJ_MAP_THEME`：杂志=黛青、手账=陶橘砂色、画廊=香槟金）。
- 客户端导航**无管理端入口**（按需求移除），管理端原型直访 `admin.html`，实装后走 `/admin` 路由。

## 设计 Token（杂志风为基准）

- 纸白 `#FAF9F6` / 墨色 `#1A1A1A` / 黛青（强调）`#2F4A5C`；手账风：米纸 `#F6EFE3` / 陶橘 `#C4622D` / 鼠尾草 `#8A9B6E`；画廊风：墨黑 `#0F1317` / 香槟金 `#C9A96A`
- 标题与数字：宋体（Mac 上为 Songti SC；手账风楷体 Kaiti SC 做注脚）；生产环境 self-host 思源宋体子集化 woff2
- 正文：系统无衬线；间距 4px 基数；断点 1024 / 640
- 占位"照片"为 CSS 渐变色块，上线后即真实相册图

## 原型中已假装成立的约定

- 图片懒加载、缩略图/大图两档（真实后端 Pillow 管线）
- 地图数据 = 城市字典 + 景点坐标自动聚合
- 管理端"地图选点/相册插图"为静态占位交互
