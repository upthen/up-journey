# up-journey 高保真原型

方向已定：**温暖手账风**，现有 A/B 两版决赛；杂志风与画廊风归档参考。数据全部为假数据，地图为真实 ECharts 渲染。

## 查看

```bash
cd docs/prototype
python3 -m http.server 8613
# 打开 http://localhost:8613/compare.html（风格对比导航）
```

> 需要通过 HTTP 服务访问（地图要 fetch 本地 GeoJSON，直接双击 file:// 会跨域）。

## 手账风两版（决赛圈，各 3 页：首页 / 足迹 / 旅行详情）

| 版本 | 位置 | 特征 |
|---|---|---|
| A · 拼贴版 | `warm/` | 装饰密度高：处处胶带贴纸、三色便签统计、邮戳年份、楷体粗标题 |
| B · 精修版 | `warm2/` | 去 AI 味精修：扉页点线统计、宋体标题+楷体注脚分层、陶橘一主色、胶带只贴照片与地图、照片颗粒做旧、汉字年份「二〇二四」 |

两版共用 `assets/map.js`（`UJ_MAP_THEME` 换配色）与 GeoJSON；拍立得、登机牌、锯齿时间轴为共享设计语言。

## 归档参考（已排除：太正式，不贴家庭相册主题）

- 杂志编辑风：根目录 4 页（首页 / 足迹 / 详情 / 管理端）
- 深色画廊风：`gallery/` 2 页（首页 / 足迹）

## 其他约定

- 客户端导航**无管理端入口**（按需求移除），管理端原型直访 `admin.html`，实装后走 `/admin` 路由。
- 字体：标题宋体（Mac 上 Songti SC）、注脚楷体（Kaiti SC）、正文系统无衬线；生产环境 self-host 思源宋体/楷体子集化 woff2。
- 断点 1024 / 640；占位"照片"为 CSS 渐变色块，上线后即真实相册图。
