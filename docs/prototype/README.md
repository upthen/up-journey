# up-journey 高保真原型

**展示端方向已定稿：v4 流程式体验（`v4/`）**——开场帷幕 → 全屏地图 → 景点故事面板 → 完整游记，
层层递进；另有编年（时间轴）与游记名录两条逃生线。视觉基因沿用 v3 暖现代（`modern/`）。
决策记录见 `docs/adr/0001-visual-style-warm-scrapbook.md`（已重写为 v3 视觉 + v4 信息架构）。
数据全部为假数据，地图为真实 ECharts 渲染，照片为真实旅行图（`assets/img/`）。

## 查看

```bash
cd docs/prototype
python3 -m http.server 8613
# 打开 http://localhost:8613/compare.html（风格对比导航）
```

> 需要通过 HTTP 服务访问（地图要 fetch 本地 GeoJSON，直接双击 file:// 会跨域）。

## v4 流程式（定稿实装蓝本）

| 页面 | 文件 | 内容 |
|---|---|---|
| 01 全屏地图 | `v4/index.html` | 开场帷幕（一句话 + 展开地图）；地图占满视口，景点带「名字 · 年份」标注、路线动画；底部年份坞筛选；左上统计旗；点击景点右侧滑出「02 · 在这里发生了什么」故事面板（照片、简介、缩略图、入口 CTA） |
| 编年 | `v4/timeline.html` | 时间这条线：粘性年份钉（分组内钉住 + 毛玻璃）+ 旅行主节点卡片（封面/日期/路线/标签/成员）+ 按天子行程（D1…）+ 滚动渐显 |
| 03 完整游记 | `v4/trip.html` | Hero 照片 + 标题行、正文叙事（图文混排）、侧栏速览卡（这次旅行 / 行程小地图 / 按天行程）、三个景点图库、上一篇/下一篇 |
| 逃生线 | `v4/list.html` | 游记名录（卡片流），给"不想在地图上找"的人 |

导航仅 地图 / 编年 / 游记名录。核心样式 `assets/style-flow.css`，地图逻辑 `assets/map-flow.js`（数据驱动的 SPOTS/TRIPS/PROVINCES）。

## 归档参考（未采用）

- `warm/`：温暖手账 A 拼贴版——手作感最强，被 v3 产品级语言取代（ADR-0001 已重写记录全部演进）
- `warm2/`：手账 B 精修版——减法方向错误（越改越失气质）
- 根目录 4 页：杂志编辑风——太正式
- `gallery/` 2 页：深色画廊风——展馆气质过重

## 其他约定

- 客户端导航**无管理端入口**；管理端原型 `admin.html`（独立的 Element Plus 后台），实装走 `/admin` 路由。
- 字体：正文系统无衬线；生产 self-host 思源宋体/黑体子集化 woff2。
- 断点 1024 / 640；照片为真实图（原图 ~1600px，上线后来自 NAS 相册目录缩略缓存）。
