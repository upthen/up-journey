# ADR-0001: 展示端视觉风格定稿——温暖手账·拼贴版

日期：2026-09-01
状态：已接受（accepted）

## 背景

up-journey v1 原型阶段共做了三套风格（杂志编辑风 / 温暖手账风 / 深色画廊风），版式各自独立。
产品所有者判定：杂志风与画廊风"太正式，不贴近家庭旅游相册的主题"，手账风胜出。
随后基于手账 A 版（拼贴版）产出 B 版（精修版：降装饰密度、收敛单主色、宋楷字体分层、照片做旧、点线扉页统计）。

## 决定

**采用 A 版·拼贴版（`docs/prototype/warm/`）为展示端最终视觉方向。**

B 版否决——产品所有者反馈"越改越 low、越改越 AI 味重"。
教训：A 版的高装饰密度（处处胶带贴纸、三色便签、楷体粗标题、邮戳年份）正是家庭相册所需的"热闹手作感"，
对它做减法反而丢失气质；后续视觉迭代只做加法微调，不做减法重构。

## 设计 Token（实装基准）

| 项 | 值 |
|---|---|
| 纸面 | 米纸 `#F6EFE3`（圆点纹理）+ 卡片 `#FFFDF7` |
| 墨色 | 深棕 `#4A3F35` / 次级 `#6B5D4E` / 灰 `#9A8A73` |
| 强调色 | 陶橘 `#C4622D`（主）、鼠尾草绿 `#8A9B6E`、砂金 `#E4C98F`（便签三色轮换） |
| 字体 | 标题/注脚：楷体（Kaiti SC，生产 self-host 子集化）；正文：系统无衬线 |
| 标志性语言 | 拍立得照片（白边+楷体注脚+随机旋转）、和纸胶带、登机牌特写卡（虚线副券+条码）、三色便签统计板、锯齿交替时间轴（邮戳年份+小飞机节点） |
| 地图配色 | 省份着色陶橘砂色阶（≥3 次 `#B4652F` / 2 次 `#D9A05B` / 1 次 `#E3C9A8` / 未去 `#EFE7D5`），城市点 `#A64B2A` |
| 断点 | 1024 / 640 |

## 影响

- Vue 实装以 `warm/` 三页（首页/足迹/详情）为像素级蓝本；`warm2/`、根目录杂志风、`gallery/` 仅存档参考。
- 生产字体子集化需同时打包楷体与思源宋体。
- 管理端不受此决策影响（独立的 Element Plus 后台）。
- 客户端导航无管理端入口（管理走 `/admin` 直达路由）。
