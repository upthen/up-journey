# ADR-0001: 展示端方向定稿——v3 暖现代视觉 + v4 流程式信息架构

日期：2026-09-01（当日多轮迭代后定稿）
状态：已接受（accepted）

## 背景

原型阶段经历三轮方向修正，均在 2026-09-01 完成：

1. **第一轮**：杂志编辑风 / 温暖手账 / 深色画廊三套。手账胜出（其余"太正式"），
   手账 B 精修版被否——反馈"越改越 low、越改越 AI 味重"。
   教训：对胜出的装饰密度做减法重构会丢气质；另一教训：凭空发明的风格打不过真实产品。
2. **第二轮**：用视觉模型逐帧拆解 Polarsteps 等真实产品的设计语言，产出 v3 暖现代
   （米白底、无边框大圆角软阴影、大照片当主角）。反馈："这版好非常多了"，
   并确认"真实产品都更好看"——从此以真实产品为基准，不再自创风格。
3. **第三轮**：产品所有者提出展示端应是**流程式、交互式、层层递进**的体验，
   而非一次性倒出所有内容的"官网首页"；入口必须是全屏地图。
   产出 v4 流程式原型，反馈："这个感觉对了，v1 按这个做。"

## 决定

**v1 展示端 = v3 的视觉语言 + v4 的信息架构。**

- **视觉基因（v3，`docs/prototype/assets/style-modern.css`）**：米白纸感底、白卡片
  无边框大圆角软阴影、珊瑚橘强调 + 深湖蓝辅助、照片当主角。
- **信息架构（v4，`docs/prototype/v4/` + `assets/style-flow.css` / `map-flow.js`）**：
  三幕层层递进——开场帷幕（一句话 + 展开地图）→ **全屏地图即首页**
  （景点带「名字 · 年份」标注、路线连线、年份坞筛选、左上统计旗）→
  点击景点右侧滑出故事面板（02 · 在这里发生了什么）→ 完整游记（03）。
  另设两条逃生线：**编年页**（粘性年份钉 + 旅行主节点/按天子节点 + 滚动渐显）与
  **游记名录页**（卡片流）；无传统官网首页。

## 设计 Token（实装基准）

| 项 | 值 |
|---|---|
| 底色 | 米白 `#F8F6F2`，卡片纯白 |
| 强调色 | 珊瑚橘 `#E8683A`（主）、深湖蓝 `#14586B`（辅/墨） |
| 卡片 | 无边框、圆角 20px、软阴影 `0 2px 6px rgba(31,42,51,.05), 0 10px 28px rgba(31,42,51,.08)` |
| 字体 | 正文系统无衬线；标题可上思源宋体（Noto Serif SC）子集化 woff2 |
| 标志性语言 | 浮岛胶囊导航、hero 大照片 + 底部渐变遮罩、地图浮岛/统计旗、年份坞、右侧滑出面板、开场帷幕、粘性年份钉时间轴 |
| 地图配色 | ECharts 主题可覆盖（`window.UJ_MAP_THEME`）：省份珊瑚橘三档到访色阶、深湖蓝点位、橘色路线 |
| 断点 | 1024 / 640 |

## 影响

- Vue 实装以 `v4/` 四页（地图/编年/名录/游记）为信息架构蓝本、`modern/` + v4 样式为像素蓝本；
  `warm/`、`warm2/`、根目录杂志风、`gallery/` 全部归档参考。
- 旧的"足迹总览页"（独立地图页）不复存在——地图即首页；编年（时间轴）与游记名录作为两条逃生线保留在 v1。
- 管理端不受此决策影响（独立的 Element Plus 后台）。
- 客户端导航无管理端入口（管理走 `/admin` 直达路由）。
