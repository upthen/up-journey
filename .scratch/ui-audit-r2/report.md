## 静态嫌疑 → 结论映射（主要排除项）

验收的另一半价值在于**排除了什么**：

- 登录 Enter 双触发（#13 嫌疑）：实测单请求，不成立；
- 双击发布重复建行程：实测**没有**重复数据（被 slug 唯一约束挡住），真实危害是并发 500 + 矛盾 toast（#15）；
- edit→new 路由复用残留表单：代码属实但现有 UI 路径不触发（保存后回列表），降级并入 #23；
- `/list?year=1999` 文案：实测标明了年份上下文，降级 P3。
