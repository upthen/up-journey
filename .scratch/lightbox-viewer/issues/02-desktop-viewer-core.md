# 02: 桌面查看器核心——变换模型 + 缩放/平移/旋转 + 工具栏与侧箭头

**What to build:** 访客在桌面打开灯箱后获得完整查看能力：滚轮缩放（1x–4x，1x=适合窗口）、双击在适合窗口↔2x 间切换、放大后拖拽平移、底部胶囊工具栏（缩小 / 计数 n/N / 放大 / 适合窗口 / 旋转 90° / 关闭）、屏幕两侧半透明圆形箭头翻页；翻页与关闭自动复位缩放/旋转/平移；加载失败的照片不阻断翻页与工具操作；单张无组时侧箭头与计数隐藏、缩放旋转仍可用。视觉遵循 ADR-0001 暖现代语言，手写零依赖。
